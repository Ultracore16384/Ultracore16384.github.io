Небольшой Проект: AuthForge

AuthForge
Регистрация и контроль сессий игроков на сервере

Майнкрафт мод, работающий на стороне сервера. Добавляет три команды для создания паролей и контроля локальных аккаунтов игроков. Был создан из-за отсутсвия аналогов на последнюю версию forge 1.12.2 на тот момент и имеет 80+ скачиваний за месяц администраторами серверов ядра forge.

О проекте

/register password password - создает новую запись uuid-password введшего игрока, если таковой не было.

/login password - сравнивает uuid-password введшего игрока с хранящимся паролем в БД, при положительном исходе переносит игрока List активных на сервере, что убирает механизмы сдерживания действий.

/changeplpassword nickname password - может быть выполнена только оператором сервера или из консоли. Меняет пароль для игрока на новый.

Хранящийся пароль хешируется алгоритмом SHA-256 (и сравнивается во время работы сервера также с хешем). БД Сохраняется с использованием библиотеки для NBT при выключении сервера перезаписанным методом класса.

Технологии

Forge Java NBT SHA-256
