Навыки

Unity

Многолетняя(4) работа с движком (почти полностью 2D проекты). Стек: шейдеры HLSL/block-based, асинхронность UniTask, многопоточность Unity Job System, процедурная генерация на разных алгоритмах, CPU/GPU, другое.

C#

Написание чистого кода, реализация архитектурных паттернов, использование возможностей языка, внедрение алгоритмов и геометрических теорем для оптимизации.

OpenTK

Работа с графическим конвейером (отправка вертексов и примитивов, загрузка текстур, отправка текстур и цветов, работа с альфа-каналом, двойная буфферизация), создание 2D графических движков для игр и приложений.

Git

Контроль репозитория, работа в команде, программное скачивание с репозиториев. Git (Desktop через терминал, как терминал в целом), Github Desktop, слияние веток.

Minecraft Modding

Создание клиентских и серверных модов в среде Eclipse. Добавление блоков и материалов, изменение генерации, добавление команд с локальной сохраняемой через NBT (или свои методы) БД, работа с сущностями, добавление механизмов.

Creating Minecraft Servers

Сборка и настройка ядра (Использовал оригинальное ядро, Forge, Spigot), настройка брендмауэра и роутера (если требуется), работа с конфигами модов и плагинов.

Web

Создание и запуск простых сайтов (на август 2026 не знаком с php и JavaScript, начал изучать html).
